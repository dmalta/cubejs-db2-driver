# Changelog

## 0.1.0

First public release.

- DB2 for z/OS and DB2 LUW data source driver for Cube 1.7 (REST and SQL API, both query planners).
- Pre-aggregations in Cube Store or in DB2 itself.
- Time dimensions on DATE columns.
- Autocommit is on for every pooled connection.
- Published as `db2-cubejs-driver`, the name Cube looks up for `CUBEJS_DB_TYPE=db2`.
